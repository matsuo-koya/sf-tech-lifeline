# SF・コンピューター技術ライフライン

生年を入力すると、SF作品・コンピューター技術・音楽の年表(1822〜2026年、全458項目)が、あなたの学齢期(幼少期・小学生・中学生・高校生・高専生・浪人・大学生・社会人)にマッピングされるWebアプリです。

テレホーダイを高校生で迎えたのか、初音ミクを中学生で浴びたのか——あなたがどんな「インターネット老人」だったのかを判定します。

- 各項目をタップすると蘊蓄コラムが開きます(全項目に現代技術とのつながりを解説)
- Wikipediaリンク、作品にはAmazon/YouTube検索リンク付き
- SF作品(赤)/実テクノロジー(青)/音楽・カルチャー(紫)のフィルタ、「すべて開く」で205年分の通読モード
- 「興味のある分野」でコンピューター・AI・ネット・SNS・モバイル・ゲーム・楽器/DTM・オーディオ・映像/CG・ウェアラブル・タブレット・VR/AR・ロボット・宇宙・量子・ブーム・アーティストごとにオン/オフ
- 進路は高卒就職・高専(5年)・短大/専門・大学(4年)・6年制大学(医歯薬獣医)・修士・博士に対応
- 浪人・留年の年数設定に対応(帯が後ろにずれます)
- どの進路にも当てはまらない場合は「社会人になった年度」を直接指定でき、卒業から就職までの空白期間は「社会人になる前」として表示されます
- アイコンはすべて自作SVG(権利フリー)

TechnoEdgeの連載「CloseBox」のために、Claudeとの対話(vibe coding)で制作しました。

## GitHub Pagesへの公開

1. このリポジトリをGitHubにpush
2. リポジトリのSettings → Pages → Source を「GitHub Actions」に設定
3. mainブランチへのpushで自動デプロイされます

リポジトリ名を`sf-tech-lifeline`以外にする場合は、`vite.config.js`の`base`を合わせて変更してください。

## データの追加

年表データは`src/events.js`(年代順)、分野の定義とUIは`src/App.jsx`にあります。項目は1行足すだけです。

```js
{ y: 1999, t: "タイトル", cat: "sf" | "tech" | "music", s: "分野キー", ic: "アイコン名", n: "蘊蓄", l: ["Wikipedia記事名"], q: "検索クエリ(任意)" },
```

- `s`は`App.jsx`の`SUBS`のキー(`pc` / `ai` / `net` / `sns` / `mobile` / `game` / `inst` / `audio` / `video` / `wear` / `tablet` / `xr` / `robot` / `space` / `quantum` / `boom` / `other` / `artist_w` / `artist_j`)。SF作品には不要です。
- `l`の記事名に`en:`を付けると英語版Wikipediaにリンクします。`"https://例|表示名"`の形式で外部リンクも張れます。
